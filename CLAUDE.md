## Repo Structure

Two independent sub-projects:
- `map/` — Interactive Astypalea energy & mobility map (Python/Folium → HTML)
- `ipoy/` — iPOY yearly island energy system modeling (placeholder, not yet implemented)

---

## map/ — Interactive Astypalea Map

### Build & run

```bash
cd map/
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Step 1: download OSM data (~30s, needs internet, writes to data/osm/)
python scripts/fetch_osm.py

# Step 2: build clean data files
python scripts/build_energy_data.py
python scripts/build_mobility_data.py
python scripts/build_demand_zones.py

# Step 3: generate the map
python scripts/plot_map.py

open docs/map_astypalea.html
```

Steps 2–3 can be re-run without re-fetching OSM data. Step 1 output is gitignored.

### Script dependency order

```
fetch_osm.py  →  build_energy_data.py
                 build_mobility_data.py   →  plot_map.py
                 build_demand_zones.py
```

`utils.py` is a library imported by `plot_map.py`; it is not run directly.

### Data tiers

| Tier | Description | Examples |
|------|-------------|---------|
| 1 – Real, exact | From OSM; exact positions | Boundary, roads, airport |
| 2 – Real values, ~position | From PPC/HEDNO press releases; ±200m position | Solar park, diesel plant |
| 3 – Modeled | Estimated from published figures | Demand zones, road congestion |

Tier-3 data shows a `⚠ Estimated` badge in map popups.

### Adding a new layer

1. Add data file to the appropriate `data/` subdirectory
2. Add a `build_*.py` script if preprocessing is needed
3. Add a `FeatureGroup` in `plot_map.py` following the existing pattern
4. Add a legend entry in `utils.build_legend_html()`

### CRS convention

All data in EPSG:4326 (WGS84 geographic). No UTM reprojection is needed at island scale.

### Gitignored outputs

- `data/osm/` — regenerated by `fetch_osm.py`
- `docs/map_astypalea.html` — regenerated by `plot_map.py`
